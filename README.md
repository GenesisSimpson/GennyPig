# GennyPig

A friendly, responsive introduction to pigs: their curiosity, social lives, fun facts, and care needs.

## View locally

Open `index.html` in a browser. The page is self-contained and uses no external libraries or image downloads.

## Publish with GitHub Pages

The site is ready to publish from the repository's `main` branch and root folder. In the repository on GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save. GitHub Pages will publish `index.html`.
